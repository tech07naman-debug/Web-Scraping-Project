📚 Books to Scrape - Web Scraper

A Python web scraping project that extracts book data (title, price, rating, availability, and more) from Books to Scrape — a website built specifically for practicing web scraping.

🔍 Overview

This project scrapes book information across all categories and pages of the site and saves the collected data in a structured format (CSV) for further analysis or use.

✨ Features


Scrapes book title, price, star rating, availability, and product URL
Handles pagination across all book listing pages
Supports scraping by category or the entire catalogue
Exports data to CSV
Includes error handling for failed requests
Respects the site's structure with clean, readable code


🛠️ Tech Stack


Python 
Requests – for making HTTP requests
BeautifulSoup4 – for parsing HTML
Pandas – for data cleaning and export
